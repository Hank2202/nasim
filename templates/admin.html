Before you start
  1. Choose the game. Now set to {{ rules.name }}, {{ state.game_settings.scenario_name }}. Open setup
  2. Put the map on the big screen. Open the projector ↗
  3. Let everyone join. They scan the QR code on the projector (or open {{ server_url }}), tap their nation and type its passcode. Passcode cards to print ↗
    These are the default passcodes, which are easy to guess.
  4. Start the clock with the green button at the top when everyone is in. You can pause it at any time.
Who is connected

A phone that sleeps counts as gone for now, and comes back by itself when it wakes.

How the game runs
What happens at the end of a turn
  • Armies on the road arrive and fight.
  • Every nation eats (the amount set for this scenario; a quarter less with Efficient Cores). At 0 Grain a nation starves: {% if rules.hide_vitality %}−20 Stability{% else %}−25 Vitality, −20 Stability{% endif %}.
  • The scenario's storyline moves on (Turn 2 border incident, Turn 3 famine).
  • The clock is set for the next turn. With "Move on automatically" ticked on the setup screen it starts by itself after a short pause.
